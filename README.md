# 우리집 대탐험 — 침공편

가족 탐험대가 집 안에 침공한 세균·벌레·외계인과 싸우는 탑다운 생존 액션 게임입니다. 원래 ‘우리집 대탐험’ 프로젝트와 별도로 관리합니다.

## 플레이
https://ljs1110s-git.github.io/home-adventure/

## v2 업데이트
- 새 게임 키아트와 3D풍 캐릭터·몬스터·생활용품·가구 아트
- 금색 강조선과 큰 캐릭터 미리보기가 있는 선택 화면, 모바일 가로 스크롤 탐험가 목록
- 탐험가 13명의 기본 무기·특수능력·효과·활용 팁, 전투 중 능력 안내
- 일반 적 21종, 중간보스 4종, 최종보스 UFO; 몬스터 도감과 방별 등장 조합
- 추격·지그재그·예고 돌진·원거리 탄막·분열 패턴
- 나무 바닥과 방별 가구, 조명·입자·에너지 효과, 고해상도 렌더링, 배경 캐시
- 다섯 번째 방 및 최종보스로 이어지지 않던 진행 조건 수정

## 조작
WASD/방향키로 이동, 기본 무기는 자동 공격. 적을 공격해 특수능력 게이지를 100% 채운 뒤 스페이스로 발동합니다. ESC는 일시정지입니다. 모바일에서는 왼쪽 터치로 이동하고 오른쪽 ⚡ 버튼을 누릅니다. 선택 화면의 ‘전체 도감’ 또는 전투 중 ‘능력 안내’로 효과를 확인할 수 있습니다.

## 로컬 실행
이 폴더에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000 으로 접속합니다. 별도 빌드나 API 키는 필요하지 않습니다.

## 검증
JavaScript 문법 검사, 13명 특수능력 실행, 5개 방의 21종 적 생성·이동·렌더링, 반복 돌진과 분열, 선택·도감·일시정지 상태 전환, 3개 화면 크기 렌더 경로를 검사했습니다. Canvas 전투 화면을 실제로 래스터 렌더링해 확인했습니다. 연결된 브라우저 도구가 없어 브라우저에서의 최종 시각 검사는 수행하지 못했습니다.
