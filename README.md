# 우리집 대탐험 — 침공편

가족 탐험대가 집 안에 침공한 세균·벌레·외계인과 싸우는 탑다운 생존 액션 게임입니다. 원래 ‘우리집 대탐험’ 프로젝트와 별도로 관리합니다.

## 플레이
https://ljs1110s-git.github.io/home-adventure/

## v6 모바일 넓은 시야
- 모바일 기본 전투 배율 0.68: 가로·세로 약 1.47배의 월드가 보입니다. HUD·조이스틱·터치 버튼 크기는 그대로입니다.
- 선택 화면과 전투 중 ‘시야 넓게/기본’ 버튼으로 전환하며 설정은 브라우저에 저장됩니다.
- 화면 회전과 일시정지 중 시야 전환에서도 캐릭터를 화면 중앙에 유지합니다.
- 확대된 월드 범위로 배경·보이는 적·화면 밖 생성 위치를 계산합니다.
- 불투명 메인 캔버스 및 가능한 브라우저의 ImageBitmap 캐시로 합성·텍스처 업로드 비용을 줄입니다.
- 저사양 모드도 여유가 있으면 60 FPS를 목표로 하고, 실제 프레임 저하가 확인되면 30 FPS로 낮춥니다. 기기 성능에 따라 실제 프레임은 다릅니다.
- Chromium의 모바일 세로·가로 화면, 시야 설정 저장, 궁극기 터치 좌표 및 후반 장판 부하 검사를 수행했습니다.

## v5 기술 선택·후반 전투 수정
- 경험치를 한꺼번에 얻어도 레벨마다 기술 선택을 순서대로 처리합니다.
- 선택 중 전투 시간·몬스터·투사체를 멈추고 선택 후 누적 틱을 몰아서 실행하지 않습니다.
- 선택지를 DOM 카드로 표시하고 세대 번호로 중복·오래된 선택을 거부합니다.
- 일시정지 화면을 오래 띄워도 계속 버튼이 동작하도록 클릭 영역을 유지합니다.
- 고레벨 기술의 중복 발광, 큰 음파 텍스처, 대형 회전 오라를 저사양 모드에서 간소화합니다. 범위·피해 계산은 유지합니다.
- 장판 공간 인덱스를 재사용하고 같은 자리에 겹친 장판 표시는 합쳐 그립니다.
- 모바일의 새 기본 프리셋은 저사양입니다. 새 버전에서 수동 선택한 설정은 유지됩니다.
- 브라우저에서 연속 선택 5회·전투 정지·중복 탭 거부·일시정지 버튼을 검증했습니다. 최고 단계 기술 6개와 약 160개 이상의 장판이 쌓인 후반 상황도 별도 부하 검사했습니다.

## v4 성능 개선
- 모바일 기본 해상도 상한 축소, 프레임 저하 시 자동 저사양 전환과 수동 설정 저장
- 스프라이트·벡터 효과를 작은 캔버스에 한 번만 래스터화해 재사용
- 메뉴·결과·일시정지 화면의 불필요한 연속 전투 렌더링 중단
- 장판 충돌의 공간 분할, 저사양 장판 일괄 렌더링, 효과·사운드 중복 제한
- 기기·성능에 따른 동시 적 수 제한; 몬스터 종류·구매 강화·코인 저장 유지
- Chromium 휴대폰 화면, DPR 2, CPU 4배 제한, 동일한 초기 120마리/무기 6개 부하 설정에서 약 3.8→24 FPS를 관측했습니다. 소프트웨어 렌더링을 쓰는 테스트 환경 수치이며 실제 기기 성능을 보장하지 않습니다.

## v3 코인 상점
- 시작·캐릭터 선택·탐험 결과 화면에서 코인 상점 바로 열기
- 공격·생존·수집 및 성장 14종 영구 강화, 가격과 현재→다음 효과 표시
- 구매 가능 항목과 부족한 코인, 최대 강화 단계 표시
- 결과 화면에 이번 탐험 정산 코인과 총 보유액 표시
- 코인 차감·강화 저장·다음 탐험 적용 및 중복 정산 방지 검증
- 코인과 강화는 현재 브라우저의 localStorage에 유지됩니다.

## v2 업데이트
- 새 게임 키아트와 3D풍 캐릭터·몬스터·생활용품·가구 아트
- 금색 강조선과 큰 캐릭터 미리보기가 있는 선택 화면, 모바일 가로 스크롤 탐험가 목록
- 탐험가 13명의 기본 무기·특수능력·효과·활용 팁, 전투 중 능력 안내
- 일반 적 21종, 중간보스 4종, 최종보스 UFO; 몬스터 도감과 방별 등장 조합
- 추격·지그재그·예고 돌진·원거리 탄막·분열 패턴
- 나무 바닥과 방별 가구, 조명·입자·에너지 효과, 고해상도 렌더링, 배경 캐시
- 다섯 번째 방 및 최종보스로 이어지지 않던 진행 조건 수정

## 조작
WASD/방향키로 이동, 기본 무기는 자동 공격. 적을 공격해 특수능력 게이지를 100% 채운 뒤 스페이스로 발동합니다. ESC는 일시정지입니다. 모바일에서는 왼쪽 터치로 이동하고 오른쪽 ⚡ 버튼을 누릅니다. 선택 화면의 ‘전체 도감’ 또는 전투 중 ‘능력 안내’로 효과를 확인할 수 있습니다.

## 로컬 실행
이 폴더에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000 으로 접속합니다. 별도 빌드나 API 키는 필요하지 않습니다.

## 검증
JavaScript 문법 검사, 13명 특수능력 실행, 5개 방의 21종 적 생성·이동·렌더링, 반복 돌진과 분열, 선택·도감·일시정지 상태 전환, 3개 화면 크기 렌더 경로를 검사했습니다. Canvas 전투 화면을 실제로 래스터 렌더링해 확인했습니다. Chromium에서 메뉴의 불필요한 재렌더 방지, 모바일 이동·능력 안내, 코인 구매·새로고침 후 유지 및 화질 설정 저장을 추가로 검사했습니다.
