# 우리집 대탐험 — 세균·벌레·외계인 침공

공개된 원본 게임의 클라이언트 코드와 에셋을 바탕으로 만든 수정본입니다. 원래 Higgsfield 사이트와 별도로 관리되는 수정본입니다.

## 플레이
https://ljs1110s-git.github.io/home-adventure/

## 실행
이 소스 폴더에서 `python -m http.server 8000`으로 실행한 뒤 http://localhost:8000 에서 엽니다.

## 조작
WASD/방향키 이동, 자동 공격, 게이지 100%에서 스페이스로 특수능력, ESC로 일시정지. 모바일은 왼쪽 터치 이동과 오른쪽 능력 버튼을 사용합니다.

## 변경
13명 이름·외형·능력 연출, 거실/주방/욕실/아이방/다락방 배경, 생활용품 무기, 먼지와 양말 적, 로봇청소기 보스, 독립 저장 키, 반응형 선택 화면. 기존 전투 패턴을 유지하면서 소재와 연출을 변경했습니다.

## 원본 확인
https://witty-lemon-843.higgsfield.app/game.js
https://witty-lemon-843.higgsfield.app/strings.js
편집용 프로젝트 주소 및 서버 소스는 공개 파일에서 확인되지 않았습니다.

## 침공 버전
적 5종: 초록 세균, 보라 세균, 붉은 딱정벌레, 청록 벌레, 외계 정찰병. 중간보스 4종과 최종보스 외계인 대왕 UFO로 변경. 거실에서 세균을 상대하고 주방에서 벌레, 욕실부터 외계인까지 함께 등장합니다.
